Diagnóstico preliminar inteligente

MediLogic es un sistema experto desarrollado en Python y Prolog que permite analizar síntomas, enfermedades crónicas y alergias para generar posibles diagnósticos con un porcentaje de afinidad.

Utilizando reglas de inferencia lógica implementadas en un archivo .pl, el sistema evalúa relaciones clínicas, detecta contraindicaciones y sugiere tratamientos seguros, mostrando además un nivel estimado de urgencia médica.

Iniciar diagnóstico

¿Cómo funciona?

1. Ingreso de datos

El paciente selecciona síntomas, nivel de severidad, alergias y enfermedades crónicas mediante formularios interactivos.

2. Inferencia lógica

El motor Prolog analiza las reglas definidas en la base de conocimiento y calcula el porcentaje de afinidad entre síntomas y enfermedades.

3. Resultado inteligente

El sistema genera un informe con diagnósticos ordenados, tratamiento sugerido seguro y nivel estimado de urgencia.
